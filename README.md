# retail-layout-simulator

Retail layout simulator for an ACM TOMACS submission.

The substantive work is on the **tomacs-tier1** branch. See open PR #1.

## What this is

A multi-floor, 2D agent-based simulator for retail shop layouts, with
dataset calibration (UCI Online Retail II + ATC Shopping Mall), Monte
Carlo / Markov / GA analytical engines, and a synthetic-ground-truth
methodology validation pipeline. See CLAUDE.md on the tomacs-tier1
branch for the architecture overview.
